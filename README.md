# PlayOff One releases

Release builds of the PlayOff One launcher for Windows, and the manifest its automatic updates read.

- `latest.json`: the newest version (read by the launcher's updater; every build is signed).
- `v<version>/PlayOffOneSetup.exe`: the installer of that version.

To install: download `PlayOffOneSetup.exe` from the newest `v...` folder and run it.
